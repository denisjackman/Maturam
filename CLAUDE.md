# Maturam

## Conventions

- Whenever a code change is committed, also add a row to the "Version
  History" table in `README.md` in that same commit: today's date, a
  bumped version number, the author, and a short reason. Bump the
  patch number for a small fix, the minor number for a feature or a
  batch of related work, and the major number for a big milestone -
  matching the existing rows.
